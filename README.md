# 🌹 Õpetaja Abiline · Помощник учителя · Teacher's Helper

Сайт, который помогает учителям делать **PowerPoint, Word и Excel** с помощью ИИ.
Работает на трёх языках (эстонский, русский, английский), в мягком «нарисованном» стиле.

* Форматы: **PowerPoint (.pptx)**, **Word (.docx)** и **Excel (.xlsx)**
* **Любой из трёх ИИ** (Gemini, ChatGPT или Claude) на выбор делает все форматы
* Виды работ: tunnitöö (классная), iseseisev töö (самостоятельная), kodutöö (домашняя), kontrolltöö (контрольная), viktoriin (викторина)
* Результат можно **посмотреть и поправить прямо на сайте** (без Microsoft 365), показать слайды на весь экран, сохранить как **веб-страницу** или распечатать / сохранить в PDF
* Для каждого ИИ есть **два поля для ключей**: если первый не сработал, сайт сам пробует второй
* Сайт разбит на отделы (меню): Tere (главная), Tee töö (создать), Tulemus (результат), Seaded (настройки), Õpetus (помощь с экскурсией со стрелками)
* Если модель Gemini перегружена, сайт сам пробует другие и запоминает рабочую
* Во время ожидания играет тихая музыка, которая **создаётся прямо в браузере** (нет файлов и нет проблем с авторскими правами). Есть пропуск трека, громкость и возможность выбрать свою музыку
* Приветствие по имени: «Tere, Viktoria!», «Привет, Viktoria!», «Hello, Viktoria!»

## Как это устроено (важно про ключи)

На сайте **нет ваших ключей**. Каждый учитель вставляет **свои** ключи в ⚙ Настройки. Они хранятся
только в браузере этого человека и отправляются только той компании, которой принадлежат
(Anthropic, OpenAI или Google). Поэтому сайт для вас бесплатный: платит каждый за себя
(у Gemini есть бесплатный уровень, так что Word и Excel можно делать без затрат).

Страницы для получения ключей (они же есть в туториале внутри сайта):

| ИИ | Где взять ключ |
|---|---|
| Claude | https://console.anthropic.com/settings/keys |
| ChatGPT (OpenAI) | https://platform.openai.com/api-keys |
| Gemini (Google) | https://aistudio.google.com/app/apikey |

> Подписка ChatGPT Plus или Claude Pro **не даёт** API-ключ. Для API на счёт отдельно кладут небольшую сумму.

Кнопка **«Vaata näidet / Посмотреть пример»** показывает всё без ключей.

## Как выложить на GitHub Pages (github.io)

1. Зайдите на https://github.com и нажмите **New repository**. Назовите, например, `opetaja-abiline`, выберите **Public**, нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите туда **содержимое этой папки**
   (`index.html`, папки `css`, `js`, `vendor`, файл `README.md`). Внизу нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Source: Deploy from a branch**,
   ветку **main** и папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты вверху этой же страницы появится ссылка вида
   `https://ВАШ-НИК.github.io/opetaja-abiline/`. Эту ссылку и отправляйте учителям.

Через командную строку то же самое:

```bash
git init -b main
git add .
git commit -m "Õpetaja Abiline"
git remote add origin https://github.com/ВАШ-НИК/opetaja-abiline.git
git push -u origin main
```

Проверить на своём компьютере до публикации: в папке сайта выполните `python3 -m http.server 8000` и откройте http://localhost:8000.

## Телефоны: iPhone и Android

- **iPhone / iPad (Safari):** кнопка «Поделиться» → «На экран “Домой”». Сайт откроется как приложение (иконка 🌹, работает без интернета для просмотра). Готовые файлы сохраняются кнопкой «Сохранить / поделиться» → «Сохранить в Файлы».
- **Android:** в Chrome меню ⋮ → «Установить приложение». Либо скачайте готовое приложение (APK) со страницы «Помощь» на сайте — его автоматически собирает GitHub Actions (`.github/workflows/android.yml`, папка `android/`). Приложение — это оболочка вокруг сайта, поэтому обновляется само вместе с сайтом. Чтобы пересобрать: вкладка Actions → «Android APK» → Run workflow.

## Режим «Ключ сайта» (Gemini без своего ключа)

В Настройках есть выбор «Свой ключ» / «Ключ сайта». Ключ сайта хранится не в коде, а в Cloudflare Worker (`worker/worker.js`) с лимитами. Как включить — `worker/README.md`. Пока `sharedUrl` в `js/config.js` пуст, карточка помечена «не настроено».

## Что ещё умеет сайт

- Варианты A и B (Word/Excel), упрощённый язык, словарик на двух языках, «свой текст» как основа работы.
- Кнопки «проще / сложнее / короче / + заданий / перевести» и своё пожелание для готовой работы.
- Новые виды Word: план урока, карточки, письмо родителям, критерии оценивания.
- Вкладка «Работы»: последние 12 работ хранятся в браузере.
- Кубик случайных тем, конфетти, талисман Роза.

## Если ИИ переименует модель

Названия моделей по умолчанию: `claude-sonnet-5-5`, `gpt-5.6-sol`, `gemini-3.5-flash`.
Если когда-нибудь появится ошибка «модель не найдена», учитель может поменять название в
⚙ Настройки → «Täpsemalt / Для продвинутых». Чтобы поменять значения по умолчанию для всех,
отредактируйте `DEFAULT_MODELS` в начале `js/ai.js`.

## Безопасность

* В `index.html` стоит политика безопасности (CSP): страница может связываться только с тремя ИИ-сервисами.
* Не вставляйте ключи в код и не публикуйте их на GitHub.
* Ключи в браузере учителя: на общем школьном компьютере нужно снять галочку «запомнить» или нажать «Забыть все ключи».
* ИИ может ошибаться: факты, даты и язык нужно проверять. Не вводите данные учеников.

Лицензии библиотек лежат в папке `vendor/` (файлы `LICENSE-*`).

## Сложность, расширенное управление, перенос на другой телефон
- Сложность — слайдер и поле 1–10 (кнопки «лёгкая / средняя / сложная» ставят 3 / 5 / 8).
- «Расширенное управление» (на странице «Создать»): время, тон, подход, число заданий каждого типа, длина текста задания, баллы, строки для ответа, подсказки, количество пунктов на слайде, шрифт, поля, ориентация листа, шкала оценок и др. Пустое поле = автоматически. Наборы настроек можно сохранять под именем.
- Ключи и настройки лежат в браузере одного устройства. Чтобы тот же сайт работал на другом телефоне или компьютере: Настройки → «Другое устройство» → скопировать код переноса → вставить его там. Либо включите «Ключ сайта» (`worker/deploy.ps1`) — тогда ключ вообще не нужен.
