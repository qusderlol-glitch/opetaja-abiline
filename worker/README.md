# «Ключ сайта» — как включить (один раз, ~10 минут, бесплатно)

Чтобы учительница могла пользоваться сайтом **без своего ключа**, на сайте есть режим «Ключ сайта».
Настоящий ключ Gemini при этом **нигде не лежит в коде сайта** — он хранится в маленьком «посреднике»
на Cloudflare (Worker). Сайт отправляет посреднику запрос, тот подставляет секретный ключ, спрашивает Gemini
и возвращает ответ. Плюс там стоят лимиты (по человеку и на весь сайт в день), чтобы никто не сжёг ваш ключ.

Всё это делаете вы сами в своём аккаунте — пароли и ключи никому передавать не нужно.

## 1. Аккаунт
1. Зайдите на https://dash.cloudflare.com/sign-up и создайте бесплатный аккаунт (карта не нужна).

## 2. Создать Worker
1. Слева: **Workers & Pages** → **Create** → **Create Worker** (или «Hello World»).
2. Имя, например: `opetaja-abiline` → **Deploy**.
3. Нажмите **Edit code**, удалите всё, что там есть, и вставьте весь текст файла `worker/worker.js` из этого репозитория → **Deploy**.

## 3. Секретный ключ
1. Откройте ваш Worker → **Settings** → **Variables and Secrets** → **Add**.
2. Type: **Secret**, Name: `GEMINI_KEY`, Value: ваш ключ Gemini (из https://aistudio.google.com/apikey) → **Deploy**.

## 4. Лимиты (KV)
1. Слева: **Storage & Databases** → **KV** → **Create** → имя `opetaja-rate` → создать.
2. Вернитесь в Worker → **Settings** → **Bindings** → **Add** → **KV namespace**.
   Variable name: **`RATE`** (именно так), namespace: `opetaja-rate` → **Deploy**.
3. По желанию в **Variables** (тип Text) можно поменять лимиты:
   `DAY_LIMIT_IP` (работ в день с одного подключения, по умолчанию 30),
   `DAY_LIMIT_TOTAL` (работ в день на весь сайт, по умолчанию 250), `MODEL` (по умолчанию `gemini-3.5-flash`).

## 5. Проверка
Откройте адрес вашего Worker с `/health` в конце, например `https://opetaja-abiline.ВАШ-ПОДДОМЕН.workers.dev/health`.
Должно быть: `{"ok":true,"key":true,"kv":true}`. Если где-то `false` — шаг 3 или 4 не доделан.

## 6. Подключить к сайту
Скопируйте адрес Worker (без `/health`) и отправьте его Claude — он впишет его в `js/config.js`
(`sharedUrl`) и обновит сайт. Или откройте `js/config.js` на GitHub (карандаш ✏️) и впишите адрес сами:

```js
window.OA_CONFIG = { sharedUrl: 'https://opetaja-abiline.ВАШ-ПОДДОМЕН.workers.dev' };
```

После этого в **Настройках → «Как будете работать?»** карточка «Ключ сайта» станет активной,
а новые посетители без ключа будут начинать с неё автоматически.

## Безопасность
- Ключ Gemini хранится только в секрете Worker; в репозитории и на сайте его нет.
- Посредник принимает запросы только от страницы `https://qusderlol-glitch.github.io`.
- Размер запроса ограничен, лимиты в день — по подключению и общий. Если вся квота сгорела, сайт предложит
  попробовать завтра или переключиться на «Свой ключ».
- Если ключ когда-нибудь утечёт — в aistudio.google.com удалите его и создайте новый, потом обновите секрет `GEMINI_KEY`.
